## Done so far (committed and live)

- **Agent-readable exports**: `llms.txt`, `llms-full.txt`, `data.json`, `sitemap.xml`. Generated by `node scripts/build.js`, which parses the HTML pages. Run it after any content edit and commit the outputs. It also copies `llms.txt` into the root repo if that checkout exists.
- **SEO**: every page has `<meta description>`, canonical, Open Graph, Twitter card, `<link rel="alternate">` to `llms.txt`/`data.json`, and schema.org JSON-LD (`Person`+`WebSite` on index, `Person` on about, `ItemList` on projects, `CollectionPage` on essays, `Article` on the essay). `essay-template.html` is `noindex`.
- Search Console reported "Duplicate without user-selected canonical" — cause was `/portfolio/` vs `/portfolio/index.html`, both 200. Canonical tags now fix it. Suggested but not yet done: change internal `href="index.html"` links to `href="./"`. User still needs to click "Validate fix" and request indexing in Search Console.
- The `index.html` meta description mentions the March 2026 research; it is the only meta not generated, update by hand when "Now" changes.
